# Sources and redistribution

Cartogram separates **generated spatial data** from **reference material** used to create or verify it.

## Reference sources

The Night City 2045 work has used official Cyberpunk RED material, including the Night City 2045 map and district maps, plus other R. Talsorian Games references where relevant.

Official PDFs and other copyrighted source artwork should not be committed to this public repository unless redistribution rights are explicitly established. Keep source filenames and page/object provenance in generated-data metadata instead.

Known reference files include:

- `RTG-CPR-Night_City_2045-150dpi.pdf`
- `RTG-CPR-DLC-NightCityAtlasv1.01.pdf`
- `Night+City2045_2 (1).skp` (source model used for building extraction; redistribution status should be checked before committing the original model)

Other Cyberpunk RED PDFs may inform later Spaciel features but are not Cartogram source assets merely because they are available during development.

## Generated assets

The generated files currently intended for migration are:

- `night_city_2045_road_graph_v12.geojson`
- `night_city_buildings_wireframe_3d.json`

Their canonical repository locations are documented in `data/night-city-2045/README.md`.
